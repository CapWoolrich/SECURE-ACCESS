# Siguientes pasos

## 1. Cambiar la repo a privada

La repo aparece como publica. Este proyecto debe ser privado porque trata procesos de acceso aeroportuario.

Ruta en GitHub:
Settings > General > Danger Zone > Change repository visibility > Private

## 2. Implementar MVP con Codex

Objetivo del primer MVP:

- Crear app React + Vite + TypeScript.
- Crear estructura src.
- Crear rutas basicas.
- Crear formulario de acceso VIP por evento.
- Crear formulario de acceso identificado para proveedores.
- Crear pantalla de aprobacion de seguridad.
- Crear pantalla de validacion en caseta.
- Crear bitacora de auditoria.
- Crear generacion placeholder de QR y codigo corto.

## 3. Reglas obligatorias

Para accesos VIP:

- No pedir nombres de pasajeros.
- No pedir nombres de choferes.
- No pedir placas.
- No pedir telefonos.
- No pedir identificaciones.

Para proveedores:

- Si pedir nombre.
- Si pedir empresa.
- Si pedir motivo.
- Si pedir vehiculo y placa.
- Si pedir herramientas o equipo.
- Si pedir responsable interno.
